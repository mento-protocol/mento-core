## Scope

The Mento Core repository contains the smart contracts that power the Mento protocol, including:

- Exchange providers and trading limit libraries
- Broker and reserve management contracts
- Governance contracts (governance factory, timelock, watchers)
- Oracle integration (SortedOracles, ChainlinkRelayer, RedstoneRelayer)
- GoodDollar integration contracts (BancorExchangeProvider, GoodDollarExpansionController)

## Reporting a Vulnerability

If you discover a security issue in Mento Core, please **do not** open a public GitHub issue.

Instead, report it by emailing **security@mento.org** with:

1. A description of the vulnerability
2. Steps to reproduce
3. Potential impact assessment
4. Any suggested mitigations

We take all security reports seriously and will respond promptly.

See the [Security section in the main README](../README.md#security) for more details.
